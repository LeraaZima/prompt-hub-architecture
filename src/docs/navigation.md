# Навигация сервиса «Промпт-хаб»

## Компоненты навигации

### Header (статический для всех страниц)
- Логотип (ведёт на `/`)
- Ссылки: Промпт-хаб (`/hub`), База знаний (`/knowledge`), Готовые шаблоны (`/templates`)
- Ссылка "Профиль" (показывается только после авторизации, ведёт на `/profile`)
- Поисковая строка (открывает `/search?q=...`)
- Кнопка "Войти" / информация о пользователе и кнопка "Выйти"

### Sidebar (контекстный – только на странице `/hub`)
- Фильтр по тегам (клик по тегу → фильтрация)
- Фильтр "Только избранное"
- Кнопка "Все промпты" для сброса фильтра

### Footer (статический везде)
- Ссылки на GitHub проекта, документацию, контакты
- Копирайт

### ThemeToggle (кнопка переключения темы)
- Круглая кнопка в правом нижнем углу
- Переключает между светлой и тёмной темой
- Сохраняет выбор в localStorage

## Типы навигации
- **Глобальная**: Header с основными разделами
- **Контекстная**: Sidebar с фильтрами (только на `/hub`)
- **Утилитарная**: поиск, кнопка входа/выхода, переключение темы
