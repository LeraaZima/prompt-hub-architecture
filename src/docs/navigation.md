# Навигация сервиса «Промпт-хаб»

## Компоненты навигации

### Header (статический для всех страниц)
- Логотип (ведёт на `/`)
- Ссылки: Промпт-хаб (`/hub`), База знаний (`/knowledge`), Готовые шаблоны (`/templates`), Личный кабинет (`/profile`)

### Sidebar (контекстный – только на странице `/hub`)
- Фильтры по тегам
- Фильтр по популярности
- Чекбокс «Только избранное»

### Footer (статический везде)
- Ссылки на GitHub проекта, документацию, контакты

### Breadcrumbs (динамические)
- Реализация на основе `useLocation()` из React Router DOM
- Пример: `Главная / hub / prompt / 123`
- Автоматически декодирует URL-encoded символы
