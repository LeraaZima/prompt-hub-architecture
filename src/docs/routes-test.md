# Ручное тестирование маршрутов

1. Главная `/` → открывается без ошибок
2. Промпт-хаб `/hub` → отображается Sidebar
3. Редактор `/editor` → заглушка
4. База знаний `/knowledge` → заглушка
5. База исследований `/research` → заглушка
6. Готовые шаблоны `/templates` → заглушка
7. Личный кабинет `/profile` → заглушка
8. Мои шаблоны `/profile/my-templates` → заглушка
9. Избранное `/profile/favorites` → заглушка
10. Несуществующий маршрут `/something` → страница 404 (пока не настроена, но роутер возвращает пустую страницу)
