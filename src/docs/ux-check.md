# UX-проверка сервиса «Промпт-хаб»

## Сценарий 1: Пользователь ищет промпт, копирует и добавляет в избранное

1. Заходит на главную (`/`)
2. Нажимает «Промпт-хаб» в хедере → попадает на `/hub`
3. Выбирает фильтр по тегу «coding»
4. Нажимает на кнопку «📋» у карточки → текст копируется, появляется ✅
5. Нажимает «🤍» → сердечко становится красным ❤️, промпт добавляется в избранное
6. Переходит в профиль `/profile/favorites` → видит добавленный промпт

**Мёртвые концы?** Нет. Из `/profile/favorites` можно вернуться в каталог через хедер.

**Улучшения:** Добавить уведомление «Скопировано» и «Добавлено в избранное».

## Сценарий 2: Пользователь создаёт свой шаблон из готового

1. Авторизуется → `/profile`
2. Переходит в «Готовые шаблоны» → `/templates`
3. Выбирает шаблон «Код-ревью ассистент»
4. Нажимает «Использовать» → открывается редактор с предзаполненным текстом
5. Редактирует, заполняет поля, сохраняет → попадает в «Мои шаблоны»
6. Видит созданный промпт в списке

**Мёртвые концы?** Нет. Все действия завершены, пользователь видит результат.

## Сценарий 3: Переключение тёмной/светлой темы

1. На любой странице нажимает кнопку 🌙 в правом нижнем углу
2. Тема переключается на тёмную, фон становится тёмным
3. Текст становится светлым, теги меняют цвет
4. При перезагрузке страницы тема сохраняется

**Мёртвые концы?** Нет.

## Выводы
- Навигация интуитивно понятна
- Фильтры работают корректно
- Тёмная тема поддерживается
- Копирование в буфер работает
- Редактор с подсветкой синтаксиса удобен
