# UX-проверка сервиса «Промпт-хаб»

## Сценарий 1: Новый пользователь ищет промпт и добавляет в избранное

1. Заходит на главную (`/`)
2. Нажимает «Промпт-хаб» в хедере → попадает на `/hub`
3. Выбирает фильтр «Популярные»
4. Нажимает на карточку промпта → открывается страница `/hub/prompt/123` (условно)
5. Нажимает «❤️ Добавить в избранное» → промпт сохраняется
6. Переходит в профиль `/profile/favorites` → видит добавленный промпт

**Мёртвые концы?**  
Нет. Из `/profile/favorites` можно вернуться в каталог через хедер (ссылка «Промпт-хаб») или через логотип.

**Улучшения:**  
- Добавить уведомление «Добавлено в избранное» с кнопкой «Перейти в избранное».
- На странице `/hub/prompt/123` показывать, добавлен ли уже этот промпт в избранное (иконка сердечка залита).

---

## Сценарий 2: Пользователь создаёт свой шаблон и публикует

1. Авторизуется → `/profile`
2. Выбирает «Мои шаблоны» → `/profile/my-templates`
3. Нажимает «Создать» → открывается редактор `/editor`
4. Сохраняет → попадает обратно в «Мои шаблоны»
5. Пытается поделиться → отмечает чекбокс «Опубликовать в хабе» и сохраняет
6. После публикации остаётся на странице `/profile/my-templates`

**Мёртвые концы?**  
Пользователь не видит свой опубликованный промпт в каталоге, если сам не перейдёт туда.

**Улучшение:**  
Добавить после успешной публикации ссылку или кнопку:  
«Посмотреть свой промпт в каталоге», ведущую на `/hub?author=me` (или на конкретную страницу промпта).

## Дополнительные проверки

### Переходы между основными разделами
- Из любого места можно вернуться на главную через логотип.
- Хлебные крошки показывают текущий путь и позволяют перейти на уровень выше.
- Sidebar появляется только на `/hub` - не мешает на других страницах.

### Консистентность навигации
- Все ссылки в хедере ведут на существующие страницы.
- Footer содержит ссылки на GitHub, документацию и контакты (внешние или внутренние).

### Рекомендации по улучшению
1. Добавить поисковую строку в хедер для быстрого поиска промптов с любой страницы.
2. На странице `/profile/favorites` добавить кнопку «Очистить всё» для массового удаления.
3. В `/editor` сделать автодополнение тегов из существующих в каталоге.
