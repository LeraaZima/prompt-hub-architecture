# Информационная архитектура сервиса «Промпт-хаб»

## Дерево страниц (ИА)

### 1. Главная страница (`/`)
- **Цель**: познакомить с сервисом, дать быстрый доступ к поиску и популярным промптам.
- **Контент**: приветствие, строка поиска, ссылки на разделы.
- **Вход**: прямая ссылка, логотип из любого места.
- **Выход**: поиск → страница результатов, ссылки на разделы → База знаний / Промпт-хаб / Готовые шаблоны / Личный кабинет.

### 2. Промпт-хаб (каталог) (`/hub`)
- **Цель**: просматривать, искать и фильтровать публичные промпты.
- **Контент**: карточки промптов, поиск по названию и тегам, фильтр по избранному, фильтр по тегам, кнопка копирования в буфер.
- **Вход**: из хедера, из главной.
- **Выход**: фильтры → обновлённый список, избранное → добавление в `/profile/favorites`, копирование → уведомление.

### 3. Редактор промптов (`/editor`, `/editor/:id`)
- **Цель**: создавать и редактировать собственные промпты с подсветкой синтаксиса.
- **Контент**: текстовый редактор с подсветкой (заголовки, переменные, стрелки, CAPS, код, декораторы, XML-теги, MetaGlyph, JSON), поля для заголовка, тегов, чекбокс публикации.
- **Вход**: из личного кабинета ("Создать"), из "Моих шаблонов" ("Редактировать"), из "Готовых шаблонов" ("Использовать").
- **Выход**: сохранение → `/profile/my-templates`, отмена → предыдущая страница.

### 4. База знаний (`/knowledge`)
- **Цель**: обучающие материалы по работе с языковыми моделями.
- **Контент**: 6 статей с категориями: Основы, Продвинутые техники, Техники обучения, Оптимизация, Шаблоны.
- **Вход**: из хедера.
- **Выход**: клик по статье → детальный просмотр с полным содержанием.

### 5. База исследований (`/research`)
- **Цель**: научные статьи, сравнения моделей, новости индустрии.
- **Контент**: список исследований (заглушка, ожидает наполнения).
- **Вход**: из хедера.
- **Выход**: внешние ссылки на оригиналы.

### 6. Готовые шаблоны (`/templates`)
- **Цель**: быстро использовать проверенные конструкции промптов.
- **Контент**: 8 шаблонов с категориями, кнопки "Копировать" и "Использовать в редакторе".
- **Вход**: из хедера.
- **Выход**: копирование → уведомление, "Использовать" → `/editor` с предзаполненным текстом.

### 7. Личный кабинет (`/profile`)
- **Цель**: управление профилем, навигация по личным разделам.
- **Контент**: форма редактирования имени и email, ссылки на "Мои шаблоны" и "Избранное".
- **Вход**: клик по "Профиль" в хедере (доступен только после авторизации).
- **Выход**: "Мои шаблоны" → `/profile/my-templates`, "Избранное" → `/profile/favorites`.

### 8. Мои шаблоны (`/profile/my-templates`)
- **Цель**: просматривать, редактировать, удалять свои промпты.
- **Контент**: список своих промптов с превью (с подсветкой синтаксиса), кнопки "Редактировать", "Удалить".
- **Вход**: из личного кабинета, из редактора после сохранения.
- **Выход**: "Редактировать" → `/editor/:id`, удаление → обновлённый список.

### 9. Избранное (`/profile/favorites`)
- **Цель**: хранить понравившиеся публичные промпты.
- **Контент**: карточки промптов, добавленных в избранное, кнопка "Удалить из избранного".
- **Вход**: из личного кабинета, из каталога.
- **Выход**: удаление из избранного → карточка исчезает, переход в каталог через хедер.

### 10. Страница поиска (`/search?q=...`)
- **Цель**: отображать результаты поиска с сохранением параметров в URL.
- **Контент**: заголовок с запросом, список результатов.
- **Вход**: из поисковой строки в хедере.
- **Выход**: переход в каталог через хедер.
