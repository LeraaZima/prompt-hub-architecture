# Информационная архитектура сервиса «Промпт-хаб»

## Дерево страниц (ИА)

### 1. Главная страница (`/`)
- **Цель**: познакомить с сервисом, дать быстрый доступ к поиску и популярным промптам.
- **Контент**: приветствие, строка поиска, карточки популярных шаблонов, ссылки на разделы.
- **Вход**: прямая ссылка, логотип из любого места.
- **Выход**: поиск → страница результатов, карточка → страница промпта, ссылки на разделы → База знаний / Промпт-хаб / Личный кабинет.

### 2. Промпт-хаб (каталог) (`/hub`)
- **Цель**: просматривать, искать и фильтровать публичные промпты.
- **Контент**: список/сетка промптов, фильтры (теги, популярность, категории), кнопка "Избранное", строка поиска.
- **Вход**: из главной (кнопка "Каталог"), из хедера, из хлебных крошек.
- **Выход**: клик по промпту → страница детального просмотра (`/hub/prompt/:id`), фильтры → обновлённый список, избранное → добавление в `/profile/favorites`.

### 3. Редактор промптов (`/editor`)
- **Цель**: создавать и редактировать собственные промпты, тестировать их.
- **Контент**: текстовый редактор с подсветкой синтаксиса, поля для заголовка, тегов, описания, кнопка "Сохранить", "Опубликовать", предпросмотр результата.
- **Вход**: из личного кабинета ("Создать промпт"), из "Моих шаблонов" (кнопка "Редактировать").
- **Выход**: сохранение → `/profile/my-templates`, публикация → `/hub` (опционально), отмена → предыдущая страница.

### 4. База знаний (`/knowledge`)
- **Цель**: обучающие материалы по работе с языковыми моделями, best practies.
- **Контент**: статьи, гайды, видеоуроки, разбитые по темам.
- **Вход**: из хедера, из главной (ссылка "Обучение"), из карточки промпта (ссылка "Как использовать").
- **Выход**: клик по статье → страница чтения, поиск → результаты, переход в каталог или профиль через хедер.

### 5. База исследований (`/research`)
- **Цель**: научные статьи, сравнения моделей, бенчмарки, новости индустрии.
- **Контент**: список исследований с фильтрами по дате, модели, автору, тегам.
- **Вход**: из хедера, из Базы знаний (ссылка "Перейти к исследованиям").
- **Выход**: клик по исследованию → страница детального просмотра, внешние ссылки на оригиналы.

### 6. Готовые шаблоны (`/templates`)
- **Цель**: быстро использовать проверенные конструкции промптов для типовых задач.
- **Контент**: карточки шаблонов с превью, кнопкой "Копировать" и "Использовать в редакторе".
- **Вход**: из хедера, из главной ("Популярные шаблоны"), из редактора (кнопка "Загрузить шаблон").
- **Выход**: копирование → уведомление об успехе, "Использовать в редакторе" → `/editor` с предзаполненным текстом.

### 7. Личный кабинет (`/profile`)
- **Цель**: управление профилем, просмотр активности, навигация по личным разделам.
- **Контент**: аватар, имя, статистика (количество промптов, избранных), ссылки на "Мои шаблоны", "Избранное", настройки.
- **Вход**: клик по аватару в хедере, прямая ссылка после авторизации.
- **Выход**: "Мои шаблоны" → `/profile/my-templates`, "Избранное" → `/profile/favorites`, настройки → `/profile/settings` (опционально).

### 8. Мои шаблоны (`/profile/my-templates`)
- **Цель**: просматривать, редактировать, удалять или публиковать свои промпты.
- **Контент**: список своих промптов с превью, кнопки "Редактировать", "Удалить", "Опубликовать в хабе".
- **Вход**: из личного кабинета, из хлебных крошек, из редактора после сохранения.
- **Выход**: "Редактировать" → `/editor`, "Опубликовать" → `/hub` (после подтверждения), удаление → обновлённый список.

### 9. Избранное (`/profile/favorites`)
- **Цель**: хранить понравившиеся публичные промпты для быстрого доступа.
- **Контент**: карточки промптов, добавленных в избранное, кнопка "Удалить из избранного".
- **Вход**: из личного кабинета, из каталога (после добавления промпта в избранное появляется ссылка "Перейти в избранное").
- **Выход**: клик по карточке → страница промпта, удаление из избранного → карточка исчезает, переход в каталог через хедер.
