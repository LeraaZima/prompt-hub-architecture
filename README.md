# PromptHub — сервис для работы с промптами

## О проекте
PromptHub — это онлайн-сервис для создания, редактирования и публикации промптов для языковых моделей.

## Функционал
- ✅ Редактор промптов с подсветкой синтаксиса
- ✅ Публичный каталог промптов с поиском и фильтрацией
- ✅ Готовые шаблоны с возможностью копирования и использования
- ✅ База знаний с обучающими статьями
- ✅ Личный кабинет, избранное, мои шаблоны
- ✅ Авторизация (заглушка)
- ✅ Тёмная/светлая тема
- ✅ Копирование в буфер обмена

## Технологии
- React 19
- TypeScript
- React Router DOM v7
- React Hook Form + Zod
- LocalStorage
